# 🧪 Troubleshooting Philosophy

The goal is not to memorize Linux commands.

The goal is to understand **how Linux systems work and how to find the root cause when something breaks.**

My troubleshooting process:

```text
                    PROBLEM
                       │
                       ▼
                 Define Issue
                       │
                       ▼
                Service Status
                       │
                       ▼
                 Process Check
                       │
                       ▼
                   Port Check
                       │
                       ▼
                Network / DNS
                       │
                       ▼
                Configuration
                       │
                       ▼
                  Permissions
                       │
                       ▼
                    Firewall
                       │
                       ▼
                     Logs
                       │
                       ▼
                 Root Cause
                       │
                       ▼
                      Fix
                       │
                       ▼
                    Verify
```
